    Password manager

    Xenon fills in passwords through a password manager's extension.

    Bitwarden and Proton Pass both work in Xenon: load one from Extensions, sign in, and it fills in logins and offers to save new ones. 1Password is offered too, from the Chrome Web Store, and on macOS, iCloud Passwords, which talks to Apple's Password Manager on this Mac. Sites can also sign you in with a security key.
