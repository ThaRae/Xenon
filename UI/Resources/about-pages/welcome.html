Before you start, there are three things to decide: where searches go, whether to block ads and trackers, and which password manager you use. You can keep these defaults, or choose each one yourself.

Where should searches go?

Anything you type in the address bar that isn't a web address goes here.

Private
Mainstream

To skip the search engine for one search, start it with a !bang: !w ladybird searches Wikipedia, and !gh searches GitHub.

Block ads and trackers?

Xenon has uBlock Origin's filter lists built in. They work on every site, and nothing you visit is sent anywhere to do it.

This covers ads, trackers, malware and scam sites, and cookie banners.

Use a password manager?

Xenon doesn't save passwords itself. Pick yours, and Xenon installs it and keeps it up to date.
